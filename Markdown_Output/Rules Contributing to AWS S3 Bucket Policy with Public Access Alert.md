Rules Contributing to AWS S3 Bucket Policy
with Public Access Alert

The following rules are used to detect S3 bucket policies that allow unauthorized public access.
Any one or more of these will trigger the AWS S3 Bucket Policy with Public Access Alert. Details
for each rule can be viewed by clicking the More Details link in the description.

Title

Description

Public Access in AWS
S3 Bucket Policy

Detects S3 bucket policies that allow public access by granting permissions to all principals
(Principal: "*"). This configuration can result in unauthorized data exposure and potential data
breaches.
