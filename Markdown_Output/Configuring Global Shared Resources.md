Configuring Global Shared Resources

The administrator for Stellar Cyber can pre-configure certain resources that may be shared
across multiple users, such as log filter definitions, recipient lists, scripts, and traffic-based
application filters (previously data filters) and application groups (previously tags). This optimizes
the user process, and ensures everyone is using the same parameters, where applicable. Use
the topics below for more details.
