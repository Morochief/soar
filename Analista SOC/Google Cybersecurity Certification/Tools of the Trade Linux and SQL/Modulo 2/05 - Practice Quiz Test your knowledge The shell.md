# Practice Quiz: Test your knowledge: The shell

**1. ¿Qué es el shell? (*What is the shell?*)**
- [ ] Información recibida por el sistema operativo (SO) a través de la línea de comandos (*Information received by the operating system (OS) via the command line*)
- [ ] Datos que consisten en una secuencia ordenada de caracteres (*Data consisting of an ordered sequence of characters*)
- [ ] Una instrucción que le indica a la computadora que haga algo (*An instruction telling the computer to do something*)
- [x] El intérprete de línea de comandos (*The command-line interpreter*)

**2. ¿Cuál es la diferencia entre la entrada estándar y la salida estándar? (*What is the difference between standard input and standard output?*)**
- [ ] La entrada estándar se envía desde el sistema operativo. La salida estándar se envía al sistema operativo. (*Standard input is sent from the operating system. Standard output is sent to the operation system.*)
- [x] La entrada estándar se envía al sistema operativo. La salida estándar se envía desde el sistema operativo. (*Standard input is sent to the operating system. Standard output is sent from the operating system.*)
- [ ] La entrada estándar se envía desde el Estándar de Jerarquía del Sistema de Archivos (FHS). La salida estándar se envía al FHS. (*Standard input is sent from the Filesystem Hierarchy Standard (FHS). Standard output is sent to the FHS.*)
- [ ] La entrada estándar se envía al Estándar de Jerarquía del Sistema de Archivos (FHS). La salida estándar se envía desde el FHS. (*Standard input is sent to the Filesystem Hierarchy Standard (FHS). Standard output is sent from the FHS.*)

**3. Después de que un usuario ingresa un comando en el shell, ¿qué puede devolver el shell al usuario? Selecciona dos respuestas. (*After a user inputs a command into the shell, what can the shell return to the user? Select two answers.*)**
