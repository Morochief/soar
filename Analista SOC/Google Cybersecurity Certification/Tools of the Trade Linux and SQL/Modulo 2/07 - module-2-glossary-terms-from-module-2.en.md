# Reading: Glossary terms from module 2

En este documento se consolidan los términos y definiciones clave del **Módulo 2** del **Curso 4: Linux y SQL** de la Certificación Profesional de Ciberseguridad de Google [cite: 25]. Estos conceptos son fundamentales para comprender la arquitectura de Linux, sus distribuciones y el trabajo operativo en la línea de comandos [cite: 25].

---

## Introducción del Equipo de Ciberseguridad de Google

Dominar el vocabulario técnico de Linux es un requisito esencial para comunicarte de forma efectiva dentro del Centro de Operaciones de Seguridad (**SOC**) [cite: 25]. Este glosario sirve como referencia rápida para repasar conceptos clave sobre hardware, sistemas operativos, distribuciones, gestores de paquetes e interacción a través del *shell* [cite: 25].

---

## Desarrollo Temático: Glosario de Términos del Módulo 2

* **Aplicación (*Application*):** Programa informático que ejecuta una tarea específica [cite: 25].
* **Bash (*Bourne-Again Shell*):** El *shell* predeterminado en la mayoría de las distribuciones de Linux [cite: 25].
* **CentOS:** Distribución de código abierto que está estrechamente vinculada a Red Hat [cite: 25].
* **Unidad Central de Procesamiento (*Central Processing Unit - CPU*):** El procesador principal de una computadora, utilizado para realizar tareas de cálculo general [cite: 25].
* **Comando (*Command*):** Instrucción directa que le ordena a la computadora realizar una acción [cite: 25].
* **Forensia digital (*Digital forensics*):** La práctica de recolectar y analizar datos para determinar lo sucedido tras un incidente o ataque informático [cite: 25].
* **Directorio (*Directory*):** Archivo o contenedor especial que organiza la ubicación en la que se almacenan otros archivos [cite: 25].
* **Distribuciones (*Distributions*):** Las diferentes versiones derivadas del sistema operativo Linux [cite: 25].
* **Ruta de archivo (*File path*):** La ubicación exacta de un archivo o directorio dentro de la estructura del sistema de archivos [cite: 25].
* **Estándar de Jerarquía del Sistema de Archivos (*Filesystem Hierarchy Standard - FHS*):** Componente del sistema operativo Linux que organiza la estructura y disposición de los datos [cite: 25].
* **Interfaz gráfica de usuario (*Graphical User Interface - GUI*):** Interfaz visual que utiliza íconos en pantalla para gestionar distintas tareas e interactuar con la computadora [cite: 25].
* **Disco duro (*Hard drive*):** Componente de hardware utilizado para el almacenamiento y memoria a largo plazo [cite: 25].
* **Hardware:** Los componentes físicos que integran un sistema informático [cite: 25].
* **Hardware interno (*Internal hardware*):** Los componentes físicos esenciales requeridos para el funcionamiento de la computadora [cite: 25].
* **Kali Linux™:** Distribución de código abierto de Linux ampliamente utilizada en la industria de la seguridad por sus herramientas integradas de *pentesting* y forensia [cite: 25].
* **Núcleo (*Kernel*):** Componente del sistema operativo Linux que gestiona los procesos, los recursos del sistema y la memoria [cite: 25].
* **Linux:** Sistema operativo de código abierto (*open source*) [cite: 25].
* **Paquete (*Package*):** Pieza de software que puede combinarse con otros paquetes para formar una aplicación completa [cite: 25].
* **Gestor de paquetes (*Package manager*):** Herramienta que ayuda a los usuarios a instalar, administrar, actualizar y eliminar paquetes o aplicaciones [cite: 25].
* **Parrot:** Distribución de código abierto comúnmente utilizada para tareas de seguridad, *pentesting* y forensia digital [cite: 25].
* **Prueba de penetración / Pentest (*Penetration test*):** Ataque simulado que ayuda a identificar vulnerabilidades en sistemas, redes, sitios web, aplicaciones y procesos [cite: 25].
* **Dispositivos periféricos (*Peripheral devices*):** Componentes de hardware externos conectados y controlados por el sistema informático [cite: 25].
* **Memoria de Acceso Aleatorio (*Random Access Memory - RAM*):** Componente de hardware utilizado para la memoria de trabajo a corto plazo [cite: 25].
* **Red Hat® Enterprise Linux®:** Distribución de Linux basada en suscripción comercial, diseñada específicamente para entornos empresariales [cite: 25].
* **Shell:** El intérprete de línea de comandos de un sistema operativo [cite: 25].
* **Error estándar (*Standard error / stderr*):** Mensaje de error o advertencia devuelto por el sistema operativo a través del *shell* [cite: 25].
* **Entrada estándar (*Standard input / stdin*):** Información o datos recibidos por el sistema operativo a través de la línea de comandos [cite: 25].
* **Salida estándar (*Standard output / stdout*):** Información o resultados devueltos por el sistema operativo a través del *shell* [cite: 25].
* **Datos de cadena / Cadenas de texto (*String data*):** Datos compuestos por una secuencia ordenada de caracteres [cite: 25].
* **Ubuntu:** Distribución de código abierto amigable para el usuario, ampliamente utilizada en ciberseguridad, servidores e infraestructura en la nube [cite: 25].
* **Usuario (*User*):** La persona que interactúa con el sistema informático [cite: 25].

## Puntos Clave (Key Takeaways)

* **Vocabulario de Linux:** Dominar estos términos permite comprender la estructura del sistema operativo, su jerarquía de archivos (*FHS*) y su kernel [cite: 25].
* **Distribuciones de Seguridad:** Distribuciones como Kali Linux, Parrot y Ubuntu son fundamentales para la auditoría y análisis en ciberseguridad [cite: 25].
* **Administración y Shell:** La comunicación a través de comandos en el *shell* genera flujos de entrada (*stdin*), salida (*stdout*) o error (*stderr*), gestionados mediante paquetes e instaladores [cite: 25].
