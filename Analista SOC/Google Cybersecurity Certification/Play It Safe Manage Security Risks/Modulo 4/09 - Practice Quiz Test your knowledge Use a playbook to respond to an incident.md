# Practice Quiz: Test your knowledge: Use a playbook to respond to an incident

**1. Los playbooks son documentos permanentes de buenas prácticas, por lo que un equipo de seguridad no debería realizar cambios en ellos. (*Playbooks are permanent, best-practice documents, so a security team should not make changes to them.*)**
- [ ] Verdadero (*True*)
- [x] Falso (*False*)

**2. ¿Qué acción puede tomar un analista de seguridad cuando está evaluando una alerta de SIEM? (*Which action can a security analyst take when they are assessing a SIEM alert?*)**
- [x] Analizar datos de registros y métricas relacionadas (*Analyze log data and related metrics*)
- [ ] Crear un informe final (*Create a final report*)
- [ ] Aislar un sistema de red infectado (*Isolate an infected network system*)
- [ ] Restaurar los datos afectados con una copia de seguridad limpia (*Restore the affected data with a clean backup*)

**3. Completa el espacio en blanco: Una vez que se resuelve un incidente de seguridad, los analistas de seguridad realizan varias actividades posteriores al incidente y esfuerzos de _____ con el equipo de seguridad. (*Fill in the blank: Once a security incident is resolved, security analysts perform various post-incident activities and _____ efforts with the security team.*)**
- [ ] preparación (*preparation*)
- [ ] detección (*detection*)
- [ ] erradicación (*eradication*)
- [x] coordinación (*coordination*)

**4. Una empresa experimentó recientemente una brecha de seguridad. Los profesionales de la seguridad están restaurando actualmente los datos afectados utilizando una copia de seguridad limpia que se creó antes del incidente. ¿Qué fase del playbook describe este escenario? (*A business recently experienced a security breach. Security professionals are currently restoring the affected data using a clean backup that was created before the incident. What playbook phase does this scenario describe?*)**
- [x] Erradicación y recuperación (*Eradication and recovery*)
- [ ] Actividad posterior al incidente (*Post-incident activity*)
- [ ] Contención (*Containment*)
- [ ] Detección y análisis (*Detection and analysis*)
