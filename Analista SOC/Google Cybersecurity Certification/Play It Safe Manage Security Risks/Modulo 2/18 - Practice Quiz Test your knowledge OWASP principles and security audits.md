# Practice Quiz: Test your knowledge: OWASP principles and security audits

**1. Un profesional de la seguridad examina de cerca la red de su organización y luego evalúa los riesgos potenciales para la misma. Su objetivo es garantizar que las salvaguardas y los procesos internos sean efectivos. ¿Qué concepto de seguridad describe este escenario? (*A security professional closely examines their organization’s network, then evaluates potential risks to the network. Their goal is to ensure internal safeguards and processes are effective. What security concept does this scenario describe?*)**
- [ ] Regulaciones de cumplimiento (*Compliance regulations*)
- [x] Evaluación de controles (*Controls assessment*)
- [ ] Recomendaciones de seguridad (*Security recommendations*)
- [ ] Comunicación de resultados (*Communicating results*)

**2. Completa el espacio en blanco: Una _____ de seguridad es una revisión de los controles, políticas y procedimientos de seguridad de una organización frente a un conjunto de expectativas. (*Fill in the blank: A security _____ is a review of an organization's security controls, policies, and procedures against a set of expectations.*)**
- [ ] examen (*examination*)
- [ ] encuesta (*survey*)
- [x] auditoría (*audit*)
- [ ] clasificación (*classification*)

**3. Se le solicita a un profesional de la seguridad que comunique los resultados de una auditoría de seguridad interna a las partes interesadas. ¿Qué debería incluirse en esa comunicación? Selecciona tres respuestas. (*A security professional is asked to communicate the results of an internal security audit to stakeholders. What should be included in that communication? Select three answers.*)**
- [x] Una recomendación sobre cómo mejorar la postura de seguridad de la organización. (*A recommendation about how to improve the organization’s security posture*)
- [x] Una lista de riesgos y requisitos de cumplimiento que deben abordarse. (*A list of risks and compliance requirements that need to be addressed*)
- [x] Un resumen del alcance y los objetivos de la auditoría. (*A summary of the audit's scope and goals*)
- [ ] Una lista de preguntas para que las respondan las partes interesadas. (*A list of questions for stakeholders to answer*)

**4. Un analista de seguridad deshabilita ciertas funciones de software para reducir las vulnerabilidades potenciales que un atacante podría explotar en su organización. ¿Qué principio de seguridad de OWASP describe este escenario? (*A security analyst disables certain software features to reduce the potential vulnerabilities that an attacker could exploit at their organization. Which OWASP security principle does this scenario describe?*)**
- [ ] Separación de funciones (*Separation of duties*)
- [ ] Corregir los problemas de seguridad correctamente (*Fix security issues correctly*)
- [x] Minimizar la superficie de ataque (*Minimize the attack surface*)
- [ ] Defensa en profundidad (*Defense in depth*)
