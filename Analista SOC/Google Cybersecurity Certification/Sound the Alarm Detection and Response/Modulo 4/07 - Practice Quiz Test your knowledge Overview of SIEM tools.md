# Practice Quiz: Test your knowledge: Overview of SIEM tools

**1. Fill in the blank: Google SecOps (Chronicle) uses _____ to search through unstructured logs.**
*   metadata
*   unified data model
*   entity search
*   **raw log search**

> **Justificación:** En Google SecOps (anteriormente Chronicle), la búsqueda de registros sin procesar (raw log search) se utiliza para consultar datos y logs que no están estructurados (unstructured logs).

***

**2. Which of the following is Splunk's query language?**
*   **SPL**
*   IDS
*   SQL
*   UDM

> **Justificación:** SPL (Search Processing Language) es el lenguaje nativo utilizado por Splunk para buscar, filtrar y analizar datos indexados.

***

**3. In Search Processing Language (SPL), which special character is a wildcard that can be used to substitute with any other character?**
*   **\***
*   =
*   !=
*   |

> **Justificación:** En SPL, el asterisco (`*`) funciona como un comodín (wildcard) que puede sustituir a cero, uno o múltiples caracteres en una consulta.

***

**4. Which of the following steps are part of the security information and event management (SIEM) process? Select three answers.**
*   **Normalize data so it is ready to read and analyze**
*   **Monitor activity and alerts related to intrusions**
*   **Collect and process data**
*   Index data to improve search performance

> **Justificación:** El proceso básico de una plataforma SIEM consiste en la recolección de los datos (Collect), su normalización para que tengan un formato legible y unificado (Normalize), y el monitoreo continuo para detectar intrusiones o anomalías (Monitor).
