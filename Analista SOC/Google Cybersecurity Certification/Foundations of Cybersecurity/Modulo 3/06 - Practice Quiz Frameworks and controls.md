# Practice Quiz: Test your knowledge: Frameworks and controls

### Pregunta 1
Una organización requiere que sus empleados completen un nuevo programa de capacitación sobre privacidad de datos cada año para reducir el riesgo de una brecha de datos. ¿De qué es un ejemplo este requisito de capacitación?
*(An organization requires its employees to complete a new data privacy training program each year to reduce the risk of a data breach. What is this training requirement an example of?)*

- [x] Control de seguridad *(Security control)*
- [ ] Marco de Ciberseguridad *(Cybersecurity Framework - CSF)*
- [ ] Confidencialidad de datos *(Data confidentiality)*
- [ ] Información de Identificación Personal *(Personally identifiable information - PII)*

### Pregunta 2
Complete el espacio en blanco: Un(a) _____ de seguridad es un conjunto de pautas utilizadas para construir planes que ayuden a mitigar el riesgo y las amenazas a los datos y la privacidad.
*(Fill in the blank: A security _____ is a set of guidelines used for building plans to help mitigate risk and threats to data and privacy.)*

- [ ] ciclo de vida *(lifecycle)*
- [ ] regulación *(regulation)*
- [x] marco de trabajo *(framework)*
