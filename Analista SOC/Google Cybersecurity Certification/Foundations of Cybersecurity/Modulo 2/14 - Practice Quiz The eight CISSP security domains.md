# Practice Quiz: Test your knowledge: The eight CISSP security domains

### Pregunta 1
Se te pide que investigues una alerta relacionada con un dispositivo desconocido que está conectado a la red interna de la empresa. Después de completar tu investigación, sigues las políticas y procedimientos de la empresa para implementar medidas preventivas que detendrán la amenaza potencial planteada por el dispositivo. ¿Con qué dominio de seguridad está relacionado este escenario?
*(You are asked to investigate an alert related to an unknown device that is connected to the company's internal network. After you complete your investigation, you follow company policies and procedures to implement preventative measures that will stop the potential threat posed by the device. Which security domain is this scenario related to?)*

- [ ] Seguridad de activos *(Asset security)*
- [ ] Arquitectura e ingeniería de seguridad *(Security architecture and engineering)*
- [x] Operaciones de seguridad *(Security operations)*
- [ ] Seguridad en el desarrollo de software *(Software development security)*

### Pregunta 2
Tu supervisor te pide que audites los permisos de los usuarios para los datos de nómina (salarios) para asegurarte de que ningún empleado no autorizado tenga acceso a ellos. ¿Con qué dominio de seguridad está relacionada esta auditoría?
*(Your supervisor asks you to audit user permissions for payroll data to ensure no unauthorized employees have access to it. Which security domain is this audit related to?)*

- [ ] Seguridad en el desarrollo de software *(Software development security)*
- [ ] Seguridad de activos *(Asset security)*
- [ ] Operaciones de seguridad *(Security operations)*
- [x] Evaluación y pruebas de seguridad *(Security assessment and testing)*

### Pregunta 3
Complete el espacio en blanco: Ejemplos de _____ de seguridad incluyen gestión de riesgos y seguridad, y arquitectura e ingeniería de seguridad.
*(Fill in the blank: Examples of security _____ include security and risk management and security architecture and engineering.)*

- [x] dominios *(domains)*
- [ ] redes *(networks)*
- [ ] datos *(data)*
- [ ] activos *(assets)*

### Pregunta 4
Se le pide a un profesional de seguridad que destruya y deseche discos duros viejos que incluyen información confidencial del cliente. ¿Con qué dominio de seguridad está relacionada esta tarea?
*(A security professional is asked to destroy and dispose of old hard drives that include confidential customer information. Which security domain is this task related to?)*

- [ ] Seguridad de redes y comunicaciones *(Communication and network security)*
- [ ] Gestión de riesgos y seguridad *(Security and risk management)*
- [ ] Seguridad en el desarrollo de software *(Software development security)*
- [x] Seguridad de activos *(Asset security)*
