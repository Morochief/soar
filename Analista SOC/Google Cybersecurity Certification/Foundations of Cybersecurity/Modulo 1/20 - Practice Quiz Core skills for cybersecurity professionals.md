**Pregunta 1:** ¿Cuáles de las siguientes competencias son habilidades transferibles (*transferable skills*), que probablemente sean aplicables en casi cualquier campo? *(Selecciona tres respuestas)*.

- [x] **Análisis** (*Analysis*).
- [ ] Programación.
- [x] **Resolución de problemas** (*Problem-solving*).

**Pregunta 2:** Completa el espacio en blanco: Los _____ identifican, analizan y preservan evidencia criminal dentro de redes, computadoras y dispositivos electrónicos.
- [ ] profesionales de inteligencia de negocios.
- [ ] analistas del centro de operaciones de seguridad (SOC).
- [x] **investigadores forenses digitales** (*Digital forensic investigators*).
- [ ] *hackers* éticos.

**Pregunta 3:** ¿Cuáles son ejemplos de Información de Identificación Personal Sensible (SPII) que los profesionales de ciberseguridad necesitan proteger? *(Selecciona dos respuestas)*.
- [ ] Direcciones de correo electrónico (Es PII, no SPII).
- [x] **Números de cuentas bancarias** (*Bank account numbers*).
- [x] **Registros médicos** (*Medical records*).
- [ ] Apellidos (Es PII, no SPII).

**Pregunta 4:** ¿Cuáles de las siguientes competencias son habilidades técnicas (*technical skills*) que se necesitan para convertirse en un analista de seguridad de nivel inicial (*entry-level*)? *(Selecciona dos respuestas)*.
- [ ] Redacción de regulaciones.
- [x] **Programación** (*Programming*).
- [ ] Colaboración (Es una habilidad transferible).
