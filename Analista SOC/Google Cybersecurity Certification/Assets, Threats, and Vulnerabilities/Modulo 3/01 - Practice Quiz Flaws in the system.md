# Practice Quiz: Test your knowledge: Flaws in the system

**1. Un investigador de seguridad reporta una nueva vulnerabilidad a la lista CVE®. ¿Cuáles de los siguientes criterios debe cumplir la vulnerabilidad antes de que reciba un ID CVE® oficial? (Selecciona dos respuestas)**
*(A security researcher reports a new vulnerability to the CVE® list. Which of the following criteria must the vulnerability meet before it receives a CVE® ID? Select two answers.)*
- [x] El reporte (*submission*) debe tener evidencia de respaldo. *(The submission must have supporting evidence.)*
- [ ] Debe afectar a múltiples aplicaciones. *(It must affect multiple applications.)*
- [x] Debe poder solucionarse o parchearse de forma independiente. *(It must be independently fixable.)*
- [ ] La vulnerabilidad debe ser desconocida para el desarrollador. *(The vulnerability must be unknown to the developer.)*

**2. ¿Cuáles de los siguientes son pasos en el proceso de gestión de vulnerabilidades (*Vulnerability Management Process*)? (Selecciona dos respuestas)**
*(Which of the following are steps in the vulnerability management process? Select two answers.)*
- [x] Catalogar los activos organizacionales. *(Catalog organizational assets)*
- [ ] Preparar defensas contra amenazas. *(Prepare defenses against threats)*
- [ ] Asignar un ID CVE®. *(Assign a CVE® ID)*
- [x] Identificar vulnerabilidades. *(Identify vulnerabilities)*

**3. ¿Qué capa de la estrategia de defensa en profundidad (*Defense in Depth*) es una capa de autenticación de usuario que principalmente filtra el acceso externo?**
*(Which layer of the defense in depth strategy is a user authentication layer that mainly filters external access?)*
- [x] Perímetro *(Perimeter)*
- [ ] Datos *(Data)*
- [ ] Endpoint / Dispositivo final *(Endpoint)*
- [ ] Red *(Network)*
> [!NOTE]
> La **capa perimetral** (*Perimeter Layer*) actúa como el muro exterior de un castillo digital, donde frecuentemente se requiere una autenticación estricta (como una VPN o un *Reverse Proxy*) antes de dejar pasar a alguien hacia la red interna corporativa.

**4. Una organización es atacada por una vulnerabilidad que antes era desconocida por los fabricantes y la comunidad. ¿De qué es ejemplo este exploit?**
*(An organization is attacked by a vulnerability that was previously unknown. What is this exploit an example of?)*
- [ ] Un activo *(An asset)*
- [ ] Un cifrado *(A cipher)*
- [ ] Una capa perimetral *(A perimeter layer)*
- [x] Un Zero-day *(A zero-day)*
