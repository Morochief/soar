# Practice Quiz: Test your knowledge: Cyber attacker mindset

**1. ¿Qué pasos se aplican cuando se utiliza la mentalidad de un atacante (*attacker mindset*)? (Selecciona tres respuestas)**
*(Which steps are applied when using an attacker mindset? Select three answers.)*
- [x] Identificar un objetivo. *(Identify a target)*
- [x] Determinar cómo se puede acceder a un objetivo. *(Determine how a target can be accessed)*
- [x] Evaluar los vectores de ataque de un objetivo. *(Evaluate a target’s attack vectors)*
- [ ] Mantenerse en comunicación con un objetivo. *(Stay in communication with a target)*

**2. ¿Cuál es la diferencia entre un vector de ataque y una superficie de ataque?**
*(What is the difference between an attack vector and an attack surface?)*
- [ ] Una superficie de ataque se refiere a todas las debilidades de un activo que pueden ser atacadas; un vector de ataque se refiere a una red obsoleta y vulnerable.
- [x] Un vector de ataque se refiere a las vías (*pathways*) que los atacantes usan para penetrar las defensas de seguridad; una superficie de ataque se refiere a todas las vulnerabilidades de un activo que pueden ser explotadas. *(An attack vector refers to the pathways attackers use to penetrate security defenses; an attack surface refers to all the vulnerabilities of an asset that can be exploited.)*
- [ ] Una superficie de ataque se refiere a la vía específica para explotar una debilidad; un vector de ataque se refiere a todas las debilidades de un activo que pueden ser explotadas.
- [ ] Una superficie de ataque se refiere al método específico de ataque; un vector de ataque se refiere a una red obsoleta y vulnerable.

**3. ¿Cómo pueden las empresas reducir el número de vectores de ataque que deben defender? (Selecciona tres respuestas)**
*(How can businesses reduce the number of attack vectors they must defend? Select three answers.)*
- [x] Controlando el acceso y la autorización a los activos. *(By controlling access and authorization to assets)*
- [x] Educando a los usuarios para que puedan participar en la prevención de ataques. *(By educating users so they can participate in preventing attacks)*
- [x] Implementando controles de seguridad que protejan la información. *(By implementing security controls that protect information)*
- [ ] Restringiendo totalmente el intercambio de información. *(By totally restricting information from being shared)*

**4. ¿Cuáles son ejemplos de fortalecimiento de la seguridad (*Security Hardening*)? (Selecciona tres respuestas)**
*(What are examples of security hardening? Select three answers.)*
- [ ] Reiniciar una aplicación que se ha bloqueado/caído. *(Restarting a crashed application)*
- [x] Mantener los sistemas parcheados y actualizados. *(Keeping systems patched and updated)*
- [x] Deshabilitar puertos de red no utilizados. *(Disabling unused network ports.)*
- [x] Hashear (*Hashing*) todas las contraseñas de los usuarios. *(Hashing all user passwords)*
