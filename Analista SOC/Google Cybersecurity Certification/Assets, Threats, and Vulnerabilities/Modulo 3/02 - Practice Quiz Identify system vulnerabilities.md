# Practice Quiz: Test your knowledge: Identify system vulnerabilities

**1. Completa el espacio en blanco: Una _____ de vulnerabilidades se refiere al proceso de revisión interna de los sistemas de seguridad de una organización.**
*(Fill in the blank: A vulnerability ____ refers to the internal review process of an organization’s security systems.)*
- [x] evaluación *(assessment)*
- [ ] puntuación *(scoring)*
- [ ] escáner *(scanner)*
- [ ] parche *(patch)*

**2. ¿Cuáles son los objetivos de una evaluación de vulnerabilidades (*Vulnerability Assessment*)? (Selecciona dos respuestas)**
*(What are the goals of a vulnerability assessment? Select two answers.)*
- [x] Identificar las debilidades existentes. *(To identify existing weaknesses)*
- [ ] Detectar el tráfico de red. *(To detect network traffic)*
- [ ] Auditar el cumplimiento normativo. *(To audit regulatory compliance)*
- [x] Reducir la exposición general a las amenazas. *(To reduce overall threat exposure)*

**3. ¿Cuáles de los siguientes ejemplos de remediación podrían implementarse después de un escaneo de vulnerabilidades? (Selecciona dos respuestas)**
*(Which of the following remediation examples might be implemented after a vulnerability scan? Select two answers.)*
- [ ] Identificar configuraciones erróneas en una aplicación. *(Identifying misconfigurations in an application)*
- [x] Instalar actualizaciones de software y parches. *(Installing software updates and patches)*
- [ ] Localizar vulnerabilidades en las estaciones de trabajo. *(Locating vulnerabilities in workstations)*
- [x] Capacitar a los empleados para que sigan nuevos procedimientos de seguridad. *(Training employees to follow new security procedures)*
> [!NOTE]
> *Identificar* y *localizar* son tareas que se realizan **durante** el escaneo o evaluación. Sin embargo, *instalar* parches y *capacitar* al personal son tareas de **remediación** que ocurren como respuesta directa a los hallazgos.

**4. ¿Cuáles son los dos tipos principales o clasificaciones de escaneos de vulnerabilidades? (Selecciona dos respuestas)**
*(What are two types of vulnerability scans? Select two answers.)*
- [x] Autenticados o no autenticados. *(Authenticated or unauthenticated)*
- [ ] Riesgo o amenaza. *(Risk or threat)*
- [x] Limitados o exhaustivos. *(Limited or comprehensive)*
- [ ] Parche o actualización. *(Patch or upgrade)*
