# Practice Quiz: Test your knowledge: Encryption methods

**1. ¿Qué tecnologías se utilizan en la infraestructura de clave pública (PKI) para intercambiar información de forma segura en línea? (Selecciona dos respuestas)**
*(Which technologies are used in public key infrastructure (PKI) to securely exchange information online? Select two answers.)*
- [ ] Plataforma como servicio *(Platform as a service - PaaS)*
- [x] Algoritmos de cifrado *(Encryption algorithms)*
- [x] Certificados digitales *(Digital certificates)*
- [ ] Reglamento General de Protección de Datos *(General Data Protection Regulation - GDPR)*

**2. ¿Cuáles de los siguientes elementos son requeridos cuando se utiliza cifrado (*encryption*)? (Selecciona todas las que correspondan)**
*(Which of the following elements are required when using encryption? Select all that apply.)*
- [x] Cifrado / Algoritmo *(Cipher)*
- [ ] Token *(Token)*
- [x] Llave / Clave *(Key)*
- [ ] Certificado *(Certificate)*
> [!NOTE]
> Para cualquier tipo de cifrado básico solo necesitas dos cosas: un **algoritmo (Cipher)** que mezcle los datos y una **llave (Key)** criptográfica para hacerlo (ya sea simétrica o asimétrica).

**3. Un atacante obtiene acceso a una base de datos corporativa donde las contraseñas de los usuarios están aseguradas con el algoritmo de hash SHA-256. ¿Puede el atacante "descifrar" (*decrypt*) las contraseñas de los usuarios?**
*(An attacker gains access to a database where user passwords are secured with the SHA-256 hashing algorithm. Can the attacker decrypt the user passwords?)*
- [x] No. Los algoritmos de hash no producen llaves de descifrado (son matemáticamente irreversibles). *(No. Hash algorithms do not produce decryption keys.)*
- [ ] Sí. Los algoritmos de hash producen una llave de descifrado. *(Yes. Hash algorithms produce a decryption key.)*

**4. ¿Qué término describe el hecho de ser incapaz de negar que cierta información es auténtica o que uno mismo realizó una acción?**
*(What term describes being unable to deny that information is authentic?)*
- [x] No repudio *(Non-repudiation)*
- [ ] Disponibilidad *(Availability)*
- [ ] Confidencialidad *(Confidentiality)*
- [ ] Integridad *(Integrity)*
