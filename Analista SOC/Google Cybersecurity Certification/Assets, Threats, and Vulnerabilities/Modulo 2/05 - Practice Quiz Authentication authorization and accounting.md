# Practice Quiz: Test your knowledge: Authentication, authorization, and accounting

**1. Una empresa minorista tiene a un empleado a cargo de comprar bienes, a otro empleado a cargo de aprobar las nuevas compras y a un tercer empleado a cargo de pagar las facturas. ¿Qué principio de seguridad está implementando la empresa minorista?**
*(A retail company has one employee that’s in charge of purchasing goods, another employee that's in charge of approving new purchases, and a third employee that’s in charge of paying invoices. What security principle is the retail company implementing?)*
- [ ] Menor privilegio *(Least privilege)*
- [x] Separación de funciones *(Separation of duties)*
- [ ] No repudio *(Non-repudiation)*
- [ ] Autenticación, autorización y contabilidad (AAA) *(Authentication, authorization, and accounting (AAA))*

**2. ¿Cómo se benefician las empresas al implementar tecnología de inicio de sesión único (SSO)? (Selecciona dos respuestas)**
*(How do businesses benefit from implementing single sign-on (SSO) technology? Select two answers.)*
- [ ] Agilizando el tráfico HTTP entre servidores *(By streamlining HTTP traffic between servers)*
- [x] Simplificando la gestión de usuarios *(By simplifying their user management)*
- [x] Proporcionando una mejor experiencia de usuario *(By providing a better user experience)*
- [ ] Requiririendo múltiples formas de identificación *(By requiring multiple forms of identification)*

**3. ¿Cuáles son las categorías fundamentales de los controles de acceso (AAA framework)? (Selecciona tres respuestas)**
*(What are the categories of access controls? Select three answers.)*
- [x] Contabilidad / Auditoría *(Accounting)*
- [ ] Administración *(Administration)*
- [x] Autorización *(Authorization)*
- [x] Autenticación *(Authentication)*

**4. ¿Qué credencial utiliza OAuth (Open Authorization) para autenticar a los usuarios?**
*(What credential does OAuth use to authenticate users?)*
- [ ] Un certificado digital *(A digital certificate)*
- [ ] Una cookie de sesión *(A session cookie)*
- [x] Un token de interfaz de programación de aplicaciones (API token) *(An application programming interface (API) token)*
- [ ] Un código de acceso de un solo uso (OTP) *(A one-time passcode (OTP))*

**5. ¿Qué factores utilizan los sistemas de autenticación para verificar la identidad de un usuario? (Selecciona tres respuestas)**
*(What factors do authentication systems use to verify a user's identity? Select three answers.)*
- [x] Característica (Algo que el usuario es, ej. Biometría) *(Characteristic)*

- [ ] Autorización *(Authorization)*
- [x] Conocimiento (Algo que el usuario sabe, ej. Contraseña) *(Knowledge)*
