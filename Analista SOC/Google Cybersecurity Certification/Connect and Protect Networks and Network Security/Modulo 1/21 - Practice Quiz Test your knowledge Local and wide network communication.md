# Practice Quiz: Test your knowledge: Local and wide network communication

**1. Completa el espacio en blanco: Una dirección de Protocolo de Internet (IP) es una cadena única de caracteres que identifica la _____ de un dispositivo en internet. (*Fill in the blank: An Internet Protocol (IP) address is a unique string of characters that identifies the _____ of a device on the internet.*)**
- [ ] sistema operativo (*operating system*)
- [ ] tamaño (*size*)
- [x] ubicación (*location*)
- [ ] velocidad (*speed*)

**2. ¿Qué tipo de dirección es asignada por un proveedor de servicios de internet y está vinculada a una ubicación geográfica? (*What type of address is assigned by an internet service provider and connected to a geographic location?*)**
- [ ] dirección WAN (*WAN address*)
- [ ] dirección IP privada (*Private IP address*)
- [x] dirección IP pública (*Public IP address*)
- [ ] dirección MAC (*MAC address*)

**3. Completa el espacio en blanco: Un switch utiliza una _____ de direcciones MAC para dirigir los paquetes de datos al dispositivo correcto. (*Fill in the blank: A switch uses a MAC _____ to direct data packets to the correct device.*)**
- [ ] ubicación geográfica (*geographic location*)
- [ ] red doméstica (*home network*)
- [x] tabla de direcciones (*address table*)
- [ ] dirección pública (*public address*)

**4. ¿Cuál de los siguientes es un ejemplo de una dirección IPv4? (*Which of the following is an example of an IPv4 address?*)**
- [x] 172.16.254.1 (*172.16.254.1*)
- [ ] 2001:0db8:85a3:0000:0000:8a2e:0370:7336 (*2001:0db8:85a3:0000:0000:8a2e:0370:7336*)
- [ ] 25, 443, 20 (*25, 443, 20*)
- [ ] 00-B1-D0-63-C2-26 (*00-B1-D0-63-C2-26*)
