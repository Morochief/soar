# Practice Quiz: Test your knowledge: Network communication

**1. Completa el espacio en blanco: Un _____ es una ubicación basada en software que organiza el envío y la recepción de datos entre dispositivos en una red. (*Fill in the blank: A _____ is a software-based location that organizes the sending and receiving of data between devices on a network.*)**
- [x] puerto (*port*)
- [ ] canal (*channel*)
- [ ] paquete (*packet*)
- [ ] segmento (*segment*)

**2. ¿Qué tipo de información se encuentra dentro del encabezado de un paquete IP? (*What type of information is contained within the header of an IP packet?*)**
- [ ] Una cadena de datos que indica que la transmisión de datos se ha completado (*A string of data indicating that the data transmission is complete*)
- [ ] Una explicación de cómo el número de puerto será procesado por el dispositivo receptor (*An explanation of how the port number will be processed by the receiving device*)
- [x] La dirección IP del remitente, la dirección MAC del destino y el protocolo a utilizar (*The sender’s IP address, the destination's MAC address, and the protocol to use*)
- [ ] El mensaje que necesita ser transmitido al dispositivo receptor (*The message that needs to be transmitted to the receiving device*)

**3. ¿Qué capa del modelo TCP/IP tiene protocolos que organizan las transferencias de archivos y los servicios de correo electrónico? (*Which layer of the TCP/IP model has protocols that organize file transfers and email services?*)**
- [ ] Capa de internet (*Internet layer*)
- [ ] Capa de acceso a la red (*Network access layer*)
- [x] Capa de aplicación (*Application layer*)
- [ ] Capa de transporte (*Transport layer*)

**4. ¿Qué es el Protocolo de Control de Transmisión (TCP)? (*What is the Transmission Control Protocol (TCP)?*)**
- [x] Una convención de comunicación de internet (*An internet communication convention*)
- [ ] Una aplicación de software que organiza datos (*A software application that organizes data*)
- [ ] Una dirección única que se le asigna a cada dispositivo en una red (*A unique address that every device on a network is assigned*)
- [ ] Directrices para las operaciones de red adecuadas (*Guidelines for proper network operations*)

**5. ¿Qué características comparten los modelos TCP/IP y OSI? Selecciona todas las opciones que correspondan. (*What characteristics do the TCP/IP and OSI models share? Select all that apply.*)**
- [x] Ambos modelos ilustran procesos y protocolos de red para la transmisión de datos entre dos o más sistemas. (*Both models illustrate network processes and protocols for data transmission between two or more systems.*)
- [ ] Ambos modelos tienen 7 capas. (*Both models have 7 layers.*)
- [x] Ambos modelos incluyen una capa de aplicación y una capa de transporte. (*Both models include an application and a transport layer.*)
- [x] Ambos modelos definen estándares para las redes y dividen el proceso de comunicación de red en diferentes capas. (*Both models define standards for networking and divide the network communication process into different layers.*)
