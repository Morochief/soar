## Desarrollo Temático: Glosario de Términos del Módulo 1

A continuación se presentan los términos oficiales y sus definiciones técnicas estructuradas para una consulta rápida y eficiente [cite: 25]:

*   **Ancho de banda (*Bandwidth*):** La capacidad máxima de transmisión de datos a través de una red, la cual se mide en bits por segundo [cite: 25].
*   **Computación en la nube (*Cloud computing*):** La práctica de utilizar servidores remotos, aplicaciones y servicios de red alojados en internet, en lugar de depender de dispositivos físicos locales propiedad de la empresa [cite: 25].
*   **Red en la nube (*Cloud network*):** Una colección de servidores o computadoras que almacena recursos y datos en centros de datos remotos (*remote data centers*) a los que se puede acceder exclusivamente a través de internet [cite: 25].
*   **Paquete de datos (*Data packet*):** La unidad básica de información que viaja de un dispositivo a otro dentro de una infraestructura de red [cite: 25].
*   **Hub (*Concentrador*):** Un dispositivo de red básico que retransmite o transmite en directo (*broadcasts*) información a absolutamente todos los dispositivos conectados a la red [cite: 25].
*   **Protocolo de Internet (*Internet Protocol - IP*):** Un conjunto de estándares y reglas utilizadas para gestionar el enrutamiento y direccionamiento de los paquetes de datos a medida que viajan entre los diferentes dispositivos de una red [cite: 25].
*   **Dirección de Protocolo de Internet (*IP address*):** Una cadena única de caracteres que identifica de forma inequívoca la ubicación lógica de un dispositivo en el internet exterior [cite: 25].
*   **Red de Área Local (*Local Area Network - LAN*):** Una infraestructura de red que abarca un espacio geográfico pequeño y limitado, como un edificio de oficinas, una escuela o un hogar [cite: 25].
*   **Dirección de Control de Acceso al Medio (*MAC address*):** Un identificador alfanumérico único e inmutable grabado de fábrica que se asigna a cada interfaz o dispositivo físico en una red [cite: 25].
*   **Módem (*Modem*):** Un dispositivo encargado de conectar tu *router* con el proveedor de servicios de internet, trayendo el acceso externo hacia tu red de área local (*LAN*) [cite: 25].
*   **Red (*Network*):** Un grupo o conjunto de dispositivos interconectados entre sí para intercambiar datos [cite: 25].
*   **Modelo de Interconexión de Sistemas Abiertos (*Open Systems Interconnection model - OSI*):** Un concepto estandarizado que describe las siete capas que las computadoras utilizan para comunicarse y enviar datos de forma estructurada a través de la red [cite: 25].
*   **Inspección de paquetes (*Packet sniffing*):** La práctica de capturar, interceptar e inspeccionar los paquetes de datos conforme viajan a través de una infraestructura de red [cite: 25].
*   **Puerto (*Port*):** Una ubicación basada en software dentro del sistema operativo de un dispositivo que organiza y canaliza el envío y la recepción de datos entre los equipos de la red [cite: 25].
*   **Router (*Enrutador*):** Un dispositivo de red diseñado específicamente para interconectar múltiples redes diferentes entre sí y dirigir el tráfico de datos [cite: 25].
*   **Velocidad (*Speed*):** La tasa real a la que un dispositivo envía y recibe datos a través de la infraestructura, medida en bits por segundo [cite: 25].
*   **Switch (*Conmutador*):** Un dispositivo que establece conexiones directas entre dispositivos específicos dentro de una misma red local mediante el envío y la recepción de datos orientada exclusivamente a ellos [cite: 25].
*   **Modelo TCP/IP (*TCP/IP model*):** Un marco de trabajo (*framework*) conceptual de cuatro capas utilizado para visualizar y estructurar cómo se organizan, empaquetan y transmiten los datos a través de una red [cite: 25].
*   **Protocolo de Control de Transmisión (*Transmission Control Protocol - TCP*):** Un protocolo de comunicación de internet orientado a la conexión que permite a dos dispositivos establecer un enlace lógico estable para transmitir flujos continuos de datos [cite: 25].
*   **Protocolo de Datagramas de Usuario (*User Datagram Protocol - UDP*):** Un protocolo de transporte no orientado a la conexión que no realiza un enlace previo entre los dispositivos antes de iniciar la transmisión de datos, optimizado para el rendimiento en tiempo real [cite: 25].
*   **Red de Área Amplia (*Wide Area Network - WAN*):** Una infraestructura de red que se extiende a través de una región geográfica masiva, conectando ciudades, estados o países enteros [cite: 25].

## Puntos Clave (Key Takeaways)

*   **Identificadores de Red:** La dirección IP representa la ubicación lógica de un dispositivo a nivel global, mientras que la dirección MAC es el identificador físico inmutable de la tarjeta de red en el entorno local [cite: 25].
*   **Modelos de Referencia:** El modelo TCP/IP (4 capas) y el modelo OSI (7 capas) son los marcos lógicos fundamentales para conceptualizar cómo se estructuran y transmiten los datos en tránsito [cite: 25].
*   **Conectividad Física vs. Virtual:** La infraestructura tradicional basada en hardware local (*on-premise* como *switches* o *hubs*) evoluciona de manera eficiente hacia entornos elásticos administrados en la nube (*cloud computing*) [cite: 25].
*   **Protocolos de Transporte:** TCP ofrece una transferencia confiable orientada a la conexión mediante el reenvío de errores, mientras que UDP prioriza la velocidad de transmisión en tiempo real prescindiendo de un enlace previo [cite: 25].
