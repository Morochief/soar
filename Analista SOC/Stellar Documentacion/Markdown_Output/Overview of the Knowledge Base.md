Overview of the Knowledge Base

The Stellar Cyber knowledge base (KB) is a comprehensive source for learning about Stellar
Cyber architecture, installing the product components, configuring, maintaining them, and using
the product.

Menus
There are three types of menus to support whatever scale of browser you are using to access
the knowledge base.

The brief Top menu is always displayed for any browser scaled wider than a mobile
screen. It provides you access to the Quick Start topic, the Stellar Cyber Customer
Success Portal (Support ), Alert Coverage, the Search field, and the Stellar Cyber
Chat feature at all times. The Quick Start is helpful for both analysts and administrators
to revisit as you learn the product.

The Full menu provides links to all the knowledge base content, primarily organized by
how you will be interacting with the product. As you navigate topics, your location in the
KB is highlighted in this menu. Use the highlighted topic title to locate context for the
topic, particularly when you have opened a topic from a search link or another topic.
This menu is hidden when the browser is scaled too narrowly to support both content
and navigation.

For narrowly scaled browsers (below 1280px), the full menu is hidden and instead a
dynamic Slide out menu with the same content is available. Access this menu by

selecting the stacked bar  button to the right of the search field. Navigate by selecting
chapters and topics and selecting the Back link to reverse your navigation steps. The
menu hides automatically when you select a topic.

Get Answers in Different Languages

You can use the language dropdown at the bottom of the Stellar Cyber Chat window to change
the language Stellar Cyber Chat uses to answer questions, as illustrated below.

 The chatbot usually recognizes the language you use to ask a question regardless of the
setting of the language dropdown. However, the chatbot only answers in the language
specified by the dropdown. For example, if you ask a question in Spanish with the dropdown
set to English, the chatbot typically understands and responds to the question but does so
in English. Set the dropdown to Spanish to get answers in Spanish. Or, alternatively, set it

to Auto to have the chatbot autodetect the language used and respond in the same
language.

Version Flags

The knowledge base uses color-coded version flags to call your attention to new and updated
topics and sections:

 – Green version flags indicate topics or sections that were entirely new in the

indicated release.

 – Yellow version flags indicate topics or sections that were modified in the

indicated release.

You can use version flags together with the New Articles entries in the KB's Table of Contents to
locate new and updated material quickly.

 Keep in mind that version flags are not intended as a complete historical record of changes
to the KB. Instead, they help point out new and modified material in recent releases that is
particularly noteworthy. Stellar Cyber removes older version flags over time once they have
served their purpose.

Content
The knowledge base content is organized by need to interact with the product. This helps you
find content based on the task you need to perform. The menu is structured with overview and
analysis topics first, as those are the most likely to be frequently used in the long term. Those
menu options are followed by administrative and reference topics, which will hopefully be less
needed over time as you use the product. This task-based structure augments the contextual
links in the Stellar Cyber UI, which provide UI-oriented navigation of the knowledge base.

Searching
You can use simple keywords to search the knowledge base. Use quotes to search for adjacent
words and use boolean terms, if more complex searches are required. For detailed guidance on
boolean searches in the Stellar Cyber knowledge base, refer to Searching the Knowledge
Base.
