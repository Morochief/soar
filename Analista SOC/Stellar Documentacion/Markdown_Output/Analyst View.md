Analyst View

The Dashboards | PREDEFINED | Analyst View provides a simple table listing all of the events
in a specified time frame. It provides a simple view to make it easy for you to focus on the events
that are important to you.

You can investigate the most urgent event and then easily move to the next item in the list.

 Note that when you navigate into and away from this dashboard, certain filters such as Event

Status are deselected.
