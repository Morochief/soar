Supported Sensor Operating Systems

This topic lists the operating systems Stellar Cyber supports for installation of both Linux and
Windows Server Sensors.

Supported Linux Server Sensor Operating Systems
The Linux distributions listed below are supported for Linux Server Sensor installation:

Alma Linux 8.10, 9

Amazon Linux 2 and 2023

CentOS 7, 8, 9, 10

CloudLinux 7.9

Debian 8, 9, 10, 11, 12, and 13

Kali Linux 2023.4

Linux Mint 18, 19, 20, 21

Oracle Linux 7.x, 8.x, 9.x, 10.x

Red Hat Enterprise Linux 7, 8, 9, and 10

 Fedora Linux 40+, the upstream distribution of RHEL 10, is also supported.

Rocky Linux 8, 9, 9.3

SUSE Linux Enterprise Server 12 (SP3-SP5), 15 (GA, SP1-SP7), 16 (GA)

Ubuntu 16.04, 18.04, 20.04, 21.04, 22.04, and 24.04

 These are the tested and supported versions. Installation may work successfully in other
versions. The installation script only blocks deployment in target environments with known
incompatibilities.

 Refer to Installing a Linux Server Sensor for details on the installation procedure.
