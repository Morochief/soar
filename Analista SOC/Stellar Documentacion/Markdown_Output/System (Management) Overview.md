System (Management) Overview

The System menu provides access to all the administrative tools you may need to perform.

There is a Search box and five sections of menu items: ORGANIZATION MANAGEMENT, DATA
SOURCE MANAGEMENT, INTEGRATIONS, HYPERAUTOMATION, and DATA MANAGEMENT.

In addition, there are a few menu items at the bottom of the System menu: System Action
Center, Recipients, Saved Objects, and Kibana Plugin.

To see the expanded sub-menus, go to the "System Menu" section in the Overview of New User
Interface.
