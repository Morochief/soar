Setting the Home Page

The XDR Kill Chain dashboard is the system's default home page, displayed when you first open
Stellar Cyber and when you click the Stellar Cyber logo. You can override this and set your own
personalized home page by selecting the Set as homepage menu item that drops down from
the upper right icon of Stellar Cyber user interface pages, as shown in the illustration below.

After setting your new home page, it appears every time you log in to Stellar Cyber and when
you click the Stellar Cyber logo at the upper left of the display.

You can unset your home page using either of the following techniques:

Set a new home page using the Set as homepage menu item in a different Stellar
Cyber page.

Display your current home page and selecting the Unset as homepage menu item.
This technique restores the XDR Kill Chain dashboard as your home page.
