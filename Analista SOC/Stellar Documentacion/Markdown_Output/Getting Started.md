Getting Started

Stellar Cyber Open XDR is a unified platform for Security Operations – everything from
collection, to data management, to reporting, to ML-driven detection and correlation, to
automated response. Stellar Cyber is used by both enterprises and MSSPs, as well as by
analysts, administrators, service managers, and executives. To get started with Stellar Cyber, we
recommend you review the overview content in the About Stellar Cyber section, below. This
provides an introduction to Open XDR, the Stellar Cyber architecture, best practices, and core
feature concepts. Next, depending on your role, follow the Quick Start suggestions relevant to
your function. After you have completed the relevant Quick Start suggestions you will be ready
to use the more detailed content in the Knowledge Base.

Searching and Help
Our Knowledge Base is full of procedures and reference material. As you begin to work with
Stellar Cyber, we recommend keeping a web browser open to one side of the user interface so
you can review help topics pertaining to the terms and screens you are viewing. Use the tips
below to access the Knowledge Base and understand how to refine search results.

You can access the help from the question mark button  on the user interface. The
menu displays both a contextual link for the active page in the Stellar Cyber interface,
as well as a link to the home page of the Knowledge Base.

Use the help system's left side table of contents navigation pane (for full browsers).

If you are browsing with a small screen device, the navigation is collapsed by default.
Click the  stacked bar button at the top right of the help to open a dynamic navigation
pane.

Search on partial terms (minimum of 4 characters), combined terms (boolean AND is
implicit), or more complex search constructs.

For more tips on working with the Knowledge Base, refer to Overview of the Knowledge Base.
