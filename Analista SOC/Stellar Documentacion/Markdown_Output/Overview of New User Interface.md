Overview of New User Interface
Stellar Cyber has a new user interface. This document describes how to switch themes, the
menus and icons in the new user interface, and a mapping of the legacy user interface's menus
and menu items to the new user interface's menus and menu items.
See the following:
Switching Themes

Mapping the Legacy UI Menu Items to the New UI
Switching Themes
 The default is the Dark theme.
To switch themes from Dark to Light or Light to Dark in the new user interface:
1. Locate the right-most icon in the top right corner of the screen in the new user interface.
In this example, it is a icon.
2. Click the right-most icon to view the menu items. In this example, it is a icon.
3. If you are in Dark Theme, select Light Theme to switch to Light Theme.
The user interface changes to a light theme.

4. If you are in Light Theme, select Dark Theme to switch to Dark Theme.
The user interface changes to a dark theme.
Navigating in the New User Interface
The new user interface has icons on the left side of the screen. Select the icon to expand all
the icons into text menus. Once expanded, you can navigate through the menus and use the
Search to find specific pages. The menus in the new user interface are described in the sections
that follow.
By comparison, the legacy user interface has text menus across the top of the screen, as well as
icons on the top right of the screen.
Icons in New UI
The new user interface has icons on the top right of the screen.

Click All Tenants to view the tenants menu items. There is a Search Tenants box and menu
items for the names of tenants.
Use the Search Tenants box to search for tenants by name.
Click the icon to open Notifications.
Click the icon to open Tasks. (You may not have any tasks.)
 You can also view the Task List as its own page using the System | Task Management
option.
Click the icon to view the menu items: Knowledge Base <specific article>, Knowledge Base
Home, API Docs, Resource Center, and System Information.
Click the right-most icon to view the menu items: Set/Unset as homepage, Pause Animation,
Profile, Feature Preview, Light/Dark Theme, and Logout. In this example, it is a icon.

Favorites Menu
You can add your favorite menu items to the Favorites or menu. Navigate to a menu item
and click the icon.
The selected menu item is pinned to Favorites.
Dashboards Menu
Click the icon to expand Dashboards to view the menu items in the Dashboards or
menu. There is a Search box, a menu item for Panoramic, and three sections of menu
items: PREDEFINED, CREATION, and CUSTOM.
 Click the section headings in all caps to expand or collapse the menus.
Dashboards Search Box
Use the Dashboards Search box to search for menu items within the Dashboards menu. For
example, if you search for vis, the search result is as follows.
Panoramic
Click Panoramic to access Panoramic views.

PREDEFINED
Click the icon to expand the PREDEFINED section of the Dashboards menu to view the
menu items: XDR Kill Chain, Operational View, Ingestion Dashboard, Analyst View, Malware
Sandbox Overview, Intrusion Signatures, Network Visibility, Service Visibility, File Integrity
Monitoring, and SLA Dashboard.
CREATION
Click the icon to expand the CREATION section of the Dashboards menu to view the menu
item: Dashboards.
CUSTOM
Click the icon to expand the CUSTOM section of the Dashboards menu to view the names of
custom dashboards, such as the following.
Cases Menu
Click Cases or to go to the Cases page. There are no other menu items under the Cases
menu.
Detections Menu
Click the icon to expand the Detections or menu to view the menu items: Alerts and
Detection Management.

Threat Intelligence Menu
Click the icon to expand the Threat Intelligence or menu to view the menu items: IoCs
and Feeds.
Threat Hunting Menu
Click Threat Hunting or to go to the Threat Hunting page. There are no other menu items
under the Threat Hunting menu.
Assets Menu
Click the icon to expand the Assets or menu to view the menu items: Asset Analytics and
User Behavior Analytics.
Automation Menu
Click the icon to expand the Automation or menu to view the menu items: Automation
and Action History.
Reporting Menu
Click the icon to expand the Reporting or menu to view the menu item: Reports.

System Menu
Click the icon to expand the System or menu to view the System menu items. There is a
Search box and five sections of menu items: ORGANIZATION MANAGEMENT, DATA SOURCE
MANAGEMENT, INTEGRATIONS, HYPERAUTOMATION, and DATA MANAGEMENT.
 Click the section headings in all caps to expand or collapse the menus.
In addition, there are a few menu items at the bottom of the System menu: System Action
Center, Recipients, Saved Objects, and Kibana Plugin.
System Search Box
Use the System Search box to search for menu items within the System menu. For example, if
you search for filters, the search result is as follows.
ORGANIZATION MANAGEMENT
Click the icon to expand the ORGANIZATION MANAGEMENT section of the System menu
to view the menu items: Licensing, Tenants, Tenant Groups, Users, Role-Based Access Control,
and Settings.
DATA SOURCE MANAGEMENT

Click the icon to expand the DATA SOURCE MANAGEMENT section of the System menu to
view the menu items: Sensors, Parsers, Receivers, and Data Filters.
Click the icon to expand Sensors to view the menu items: Sensors, Sensor Profiles, and
Sensor Installation.
Click the icon to expand Parsers to view the menu items: Custom Log Parsers and Log
Sources.
There are no other menu items under Receivers.
Click the icon to expand Data Filters to view the menu items: Log Filters and Traffic Filters.
INTEGRATIONS
Click the icon to expand the INTEGRATIONS section of the System menu to view the menu
items: Connectors, InSyncs, and Credential Management.

HYPERAUTOMATION
Click the icon to expand the HYPERAUTOMATION section of the System menu to view the
menu item: Auto Triage Management.
DATA MANAGEMENT
Click the icon to expand the DATA MANAGEMENT section of the System menu to view the
menu items: Enrichments and Data Management.
Additional System Menu Items
There are a few additional menu items at the bottom of the System menu: System Action Center,
Recipients, Saved Objects, and Kibana Plugin.
Click the icon to expand Saved Objects to view the menu items: Queries and Filters, Charts,
Watchlists, Saved Scripts, and Certificates.
AI Investigator Menu
Click AI Investigator or to go to the AI Investigator page. There are no other menu items
under AI Investigator.
Mapping the Legacy UI Menu Items to the New UI

The table below maps the menus and menu items in the legacy user interface to the menus and
menu items in the new user interface.
In the legacy user interface, a section heading, such as Predefined under the Visualize menu,
was not a selectable part of the path. In the new user interface, a section heading, such as
PREDEFINED under the Dashboards menu, is also not a selectable part of the path, however,
you may need to click the expand icon to see the menu items under the section heading.
In some cases, you may need to expand multiple items. For example, to select the Sensor
Profiles menu item under the System menu, expand System, expand DATA
SOURCE MANAGEMENT, and expand Sensors. You can then select Sensor Profiles.
Alternatively, you can use the Search boxes under Dashboards or System to locate a menu item.
For example, to find the Sensor Profiles menu item, type profile in the System Search box.
